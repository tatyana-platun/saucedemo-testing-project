# SauceDemo: тестирование интернет-магазина

 Pet-проект по ручному функциональному тестированию приложения [saucedemo.com](https://www.saucedemo.com). 
 Самостоятельный проект: ручное тестирование приложения с 6 типами пользователей (standard_user, locked_out_user, problem_user, performance_glitch_user, error_user, visual_user). 
Составила чек-лист из 82 проверок по 4 модулям (Login, Catalog & Cart, Checkout, UI & Navigation) и 53 тест-кейса. 
Оформила баг-репорты с шагами воспроизведения, ожидаемым и фактическим результатом, severity / priority.
